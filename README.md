## 🎯 Descrição
Aplicação web **SPA (Single Page Application)** criada como projeto final da disciplina *Desenvolvimento Front-end para Web*.  
O foco é aplicar **versionamento com Git/GitHub**, **acessibilidade (WCAG 2.1 Nível AA)** e **deploy via GitHub Pages**.

---

## 🛠️ Tecnologias
- HTML5 semântico  
- CSS3 (responsivo, acessível, modo escuro e alto contraste)  
- JavaScript modular  
- Git/GitHub (GitFlow)  
- GitHub Pages  

---

## ♿ Acessibilidade
- Estrutura semântica e navegação por teclado  
- Contraste mínimo 4.5:1  
- Suporte a leitores de tela (`alt`, `aria-label`)  
- Modo escuro e alto contraste  

---

## ⚙️ Versionamento
- Estratégia **GitFlow**  

main → versão estável
develop → desenvolvimento
feature/... → novas funções
release/... → entregas

- Commits semânticos (`feat:`, `fix:`, `docs:` etc.)  
- Issues e milestones usados para organização
